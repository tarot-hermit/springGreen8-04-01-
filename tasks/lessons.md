### [2026-04-13] DDL 테이블과 Mapper 참조 테이블 구분
- **상황**: Claude Desktop용 PPT 자료를 만들며 DB 테이블 설명을 정리했다.
- **실수**: `springGreen8.sql`에 실제 `CREATE TABLE`로 정의된 테이블 2개와 Mapper/VO가 참조하는 추가 테이블을 함께 설명해, 실제 생성 테이블이 15개처럼 보일 수 있게 했다.
- **원인**: DDL 기준의 확정 스키마와 코드 참조 기준의 필요 테이블을 명확히 분리하지 않았다.
- **규칙**: DB 설명을 만들 때는 먼저 `CREATE TABLE` 기준 실제 생성 테이블 수를 확정하고, Mapper/DAO/VO에서만 보이는 테이블은 반드시 "코드 참조 테이블" 또는 "추가 필요 테이블"로 별도 표기한다.
