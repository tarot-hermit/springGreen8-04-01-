# SpringGreen8 Claude Desktop 프로젝트 구조 설명서

## 이 문서의 목적
- 이 문서는 `Claude Desktop`이 `SpringGreen8` 프로젝트의 구조와 기능 범위를 이해할 수 있도록 설명하는 보조 문서다.
- Claude Desktop은 로컬 작업공간 전체를 자동으로 이해하지 못하므로, 발표 자료를 만들 때는 프로젝트 구조와 핵심 흐름을 별도로 전달해야 한다.
- 이 문서는 발표용 PPT, 발표 대본, 포트폴리오형 문서, 프로젝트 소개 자료를 만들 때 함께 첨부하는 것을 권장한다.

## 프로젝트 한 줄 설명
`SpringGreen8`은 영화, 드라마, 애니메이션 콘텐츠를 탐색하고 검색하며, 상세 정보 확인, 리뷰 작성, 댓글, 찜, 컬렉션, 관리자 기능까지 제공하는 `Spring MVC 기반 콘텐츠 커뮤니티 웹 프로젝트`다.

## 기술 스택
- Backend:
  - `Java 11`
  - `Spring MVC 4.3`
  - `Spring AOP / Interceptor`
- Frontend:
  - `JSP`
  - `JSTL`
  - `Bootstrap`
  - `jQuery`
- Database:
  - `MySQL`
  - `MyBatis`
- External API:
  - `TMDB API`
  - `YouTube fallback`

## 프로젝트 구조 개요

### 1. 화면(View) 구조
주요 화면은 아래 폴더에 나뉘어 있다.

- `src/main/webapp/WEB-INF/views/movie`
  - 영화, 드라마, 애니메이션 목록
  - 검색 화면
  - 영화 상세
  - TV 상세
  - 인물 상세
- `src/main/webapp/WEB-INF/views/user`
  - 회원가입
  - 로그인
  - 마이페이지
  - 프로필 수정
  - 비밀번호 찾기/변경
- `src/main/webapp/WEB-INF/views/collection`
  - 컬렉션 상세 및 관리
- `src/main/webapp/WEB-INF/views/admin`
  - 관리자 대시보드
  - 회원 관리
  - 리뷰 관리
  - 신고 관리
- `src/main/webapp/WEB-INF/views/common`
  - 공통 네비게이션
  - 푸터
  - 공통 include 파일

### 2. 컨트롤러 구조
주요 컨트롤러는 아래와 같다.

- `MovieController`

- `UserController`
  - 회원가입, 로그인, 이메일 인증, 프로필 수정, 비밀번호 변경, 계정 찾기
- `ReviewController`
  - 리뷰 작성, 수정, 삭제
- `CommentController`
  - 댓글 처리
- `CollectionController`
  - 컬렉션 생성/수정/상세/추가
- `ReportController`
  - 신고 처리
- `NotificationController`
  - 알림 관련 기능
- `WatchedController`
  - 시청 기록 관련 기능
- `AdminController`
  - 관리자 대시보드, 회원/리뷰/신고 관리
- `GlobalViewOptionsAdvice`
  - 공통 뷰 데이터 주입

  - 검색
  - 상세 정보
  - 예고편
  - 키워드
  - OTT 제공처
- `UserService / UserServiceImpl`
  - 회원 처리
- `ReviewService / ReviewServiceImpl`
  - 리뷰 로직
- `CommentService / CommentServiceImpl`
  - 댓글 로직
- `CollectionService / CollectionServiceImpl`
  - 컬렉션 로직
- `AdminService / AdminServiceImpl`
  - 관리자 통계 및 관리 기능
- `WatchedService / WatchedServiceImpl`
  - 봤어요 처리
- `WatchlistService / WatchlistServiceImpl`
  - 찜 처리

  - 이메일 인증 및 코드 발송

## 사용자가 보게 되는 핵심 기능 흐름

### 1. 콘텐츠 탐색
- 사용자는 메인 화면에서 영화, 드라마, 애니메이션 콘텐츠를 탐색할 수 있다.
- 인기 콘텐츠, 트렌딩, 개봉 예정작, 장르별 탐색이 가능하다.
- 영화, 드라마, 애니메이션이 분리된 리스트 구조를 가진다.

### 2. 검색
- 검색 화면에서 `제목` 또는 `키워드`로 콘텐츠를 찾을 수 있다.
- `# 키워드` 검색을 지원한다.
- 오타나 띄어쓰기 차이를 어느 정도 보정하는 fallback 로직이 들어 있다.
- 최근 검색어와 인기 검색어를 함께 보여준다.

### 3. 상세 페이지
- 영화 상세 페이지:
  - 줄거리
  - 예고편
  - 출연진
  - 스태프
  - 키워드
  - OTT 제공처
  - 찜 / 봤어요 / 컬렉션 추가
- 드라마 상세 페이지:
  - 줄거리
  - 시즌 선택
  - 시즌별 영상
  - 시리즈 예고편 fallback
  - 키워드
  - OTT 제공처
- 애니메이션:
  - 별도 상세 페이지가 아니라 영화 상세 또는 TV 상세 구조를 공유한다.
  - 검색과 키워드 동작은 `animation` 타입으로 구분될 수 있다.

## 예고편 처리 알고리즘
이 프로젝트의 예고편 기능은 단순히 TMDB 영상 API를 한 번 호출하는 구조가 아니다. 실제 서비스에서 영상이 비어 있거나, 예고편이 아닌 클립 영상만 노출되는 문제를 줄이기 위해 아래와 같은 단계로 설계되어 있다.

### 1. 기본 조회
- 먼저 TMDB의 한국어(`ko-KR`) 영상 목록을 조회한다.
- 결과가 없으면 영어(`en-US`) 영상 목록을 한 번 더 조회한다.

### 2. 캐시 확인
- TMDB 또는 YouTube fallback으로 확보한 예고편 결과는 캐시 테이블에 저장한다.
- 같은 콘텐츠를 다시 조회할 때는 캐시를 우선 사용해 응답 속도와 안정성을 높인다.

### 3. YouTube fallback
- TMDB 영상이 비면 YouTube 검색 fallback을 사용한다.
- 영화는 제목 후보를 기반으로 `official trailer`, `main trailer`, `trailer`, `teaser`, `preview` 같은 검색어를 조합한다.
- 드라마는 제목 후보뿐 아니라 시즌 번호, 시즌명, 스페셜 여부를 반영해 시즌 전용 검색어를 만든다.

### 4. 후보 제외 규칙
- YouTube 검색 결과 중 아래와 같은 영상은 예고편이 아니라고 판단해 제외한다.
  - 쇼츠
  - 리액션
  - 리뷰
  - OST
  - 오프닝/엔딩
  - 편집 영상
  - 클립
  - 씬 영상
  - 해설/분석 영상

### 5. 후보 점수화 기준
- 남은 후보 영상은 아래 기준으로 점수화한다.
  - 제목이 콘텐츠명과 강하게 일치하는가
  - 채널명이 콘텐츠명 또는 공식 채널과 유사한가
  - 제목에 `official`이 포함되는가
  - 제목이 `trailer`, `teaser`, `preview` 계열인가
  - 드라마의 경우 시즌 정보가 맞는가
- 점수가 높은 영상만 상위 결과로 선택한다.

### 6. 재생 가능 여부 검증
- 가능하면 YouTube 상세 API로 아래 조건을 확인한다.
  - 임베드 가능 여부
  - 공개 상태
  - 업로드 처리 상태
  - 한국(`KR`) 지역 재생 가능 여부

### 7. 드라마 추가 fallback
- 드라마 상세에서는 `선택한 시즌 영상 -> 시즌 1 영상 -> 시리즈 전체 영상` 순서로 추가 fallback이 적용된다.
- 이를 통해 특정 시즌 영상이 없더라도 최소한 시리즈 관련 예고편을 제공할 수 있다.

## 최근 개선된 핵심 포인트
이 프로젝트는 단순히 기능만 구현한 것이 아니라, 사용성 문제와 구조 문제를 점검하여 최근 아래 사항을 개선했다.

- 검색어에 `#`와 공백이 포함될 때 페이지 이동이 깨지던 문제 수정
- 페이지 이동 시 최근 검색어가 중복 적재되던 문제 수정
- 검색 정확도 향상을 위한 제목 보정 및 키워드 fallback 적용
- 영화 예고편 fallback 구조를 드라마 수준으로 보강
- 예고편 후보 필터링, 점수화, 캐시 구조 정리
- 영화 상세 페이지 키워드 섹션 추가
- 드라마 상세 페이지 키워드 섹션 추가
- 애니메이션 검색/키워드 흐름 보완
- 입력 검증 규칙 통합
- XSS/SQL 과탐 완화
- 관리자 공통 데이터 주입 구조 정리
- 비밀번호 변경 UI 연결

## 발표용 데모 추천 시나리오
아래 흐름은 발표 중 가장 자연스러운 시연 순서다.

1. 메인 홈 화면 진입
2. 영화/드라마/애니메이션 탐색 구조 설명
3. 검색창에서 `아바타 불과재 # space adventure` 입력
4. 검색 결과 확인
5. 상세 페이지에서 예고편, 키워드, 출연진 확인
6. 로그인 후 리뷰 또는 찜/컬렉션 기능 시연
7. 관리자 페이지에서 통계와 신고 처리 화면 확인

## Claude Desktop에 전달하면 좋은 설명 방식
Claude Desktop에는 아래처럼 설명하는 것이 좋다.

- 이 프로젝트는 단순 영화 정보 조회 사이트가 아니다.
- 탐색, 검색, 상세 조회, 커뮤니티, 관리자 기능이 하나의 서비스 흐름으로 연결된 웹 프로젝트다.
- 발표 자료에서는 기능 나열보다 `문제 정의 -> 구현 -> 개선 -> 결과` 흐름이 중요하다.
- 검색 기능 개선, 예고편 fallback, 사용자 기능, 관리자 기능을 반드시 강조해야 한다.
- 예고편은 단순 조회가 아니라 fallback과 후보 정렬 알고리즘이 들어간 기능이라는 점을 함께 설명해야 한다.

```text
첨부한 프로젝트 구조 설명서를 참고해서 SpringGreen8 프로젝트를 먼저 이해해줘.

이 프로젝트는 영화, 드라마, 애니메이션 콘텐츠를 탐색하고 검색하며, 상세 정보와 예고편, 키워드, OTT 정보를 제공하고, 로그인 후에는 리뷰, 댓글, 찜, 컬렉션 같은 커뮤니티 기능을 사용할 수 있는 Spring MVC 웹 프로젝트다.

특히 아래 항목은 꼭 반영해줘.

- # 키워드 검색 지원

- 영화/드라마 예고편 처리
- 예고편 후보 필터링 및 점수화 로직
- 사용자 커뮤니티 기능
- 관리자 기능
- 최근 개선 사항
```

## 이 문서를 사용할 때의 기대 효과
- Claude Desktop이 프로젝트를 더 정확하게 이해할 수 있다.
- 발표 자료가 추상적인 소개문에서 끝나지 않는다.
- 실제 구조와 기능 흐름이 반영된 발표안이 나온다.
- 발표 대본, PPT 문구, 포트폴리오형 문서 작성 시 일관성이 높아진다.
